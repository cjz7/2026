# 工作日报｜2026年10月21日

**日期：** 2026年10月21日（星期三）

**学习方向：** Linux 运维基础与服务器操作

**学习环境：** Windows 11 + WSL2 Ubuntu

**学习方式：** 命令行实操、模拟考核、错误排查

## 今日学习内容

今天主要围绕 Linux 运维基础命令及服务器常用操作开展学习，通过实际命令操作和模拟考核，进一步巩固了文件管理、远程连接、数据传输、网络检查及系统状态查看等技能。

### SSH 远程连接

练习了使用 `ssh` 连接 Linux 主机，并通过 `whoami`、`hostname`、`pwd` 等命令确认登录用户、主机名称和当前工作目录，最后使用 `exit` 正常退出远程连接。相关实操考核顺利通过。

### SCP 文件传输

完成了使用 `scp` 上传文件、从远程主机下载文件及下载时重命名的操作，并通过 `cmp` 对比文件内容，确认传输前后数据一致。

### rsync 数据备份

学习并实践了 `rsync -avh` 命令，将源目录中的文件同步至备份目录。通过再次执行同步命令，观察了未修改文件无需重复传输的特点。操作过程中出现过目录路径错误，经过检查和纠正后成功完成备份。

### `Screen` 会话管理

练习了 `Screen` 会话创建、分离、查看和恢复操作。成功创建并查看了处于 Detached 状态的会话，但在恢复时遇到会话意外结束的问题。该部分暂未完成全部考核，仍需进一步巩固。

### HTTP 文件共享服务

使用 Python 启动本地 HTTP 文件服务，并通过 `curl -I` 访问测试文件，获得 HTTP 200 OK 响应，确认服务可以正常访问。文件下载及完整性验证部分未完成本轮考核。

### Linux 网络检查

完成了 ping、`ip addr`、`ss -lnt`、`nc`、`dig` 等命令的实际操作，掌握了本机网络连通性测试、网卡 IP 地址查看、TCP 监听端口检查、SSH 端口检测及 DNS 解析查询的方法。

### 磁盘与系统状态检查

使用 `df -h`、`lsblk`、`free -h`、`uptime` 查看 Linux 磁盘空间、块设备信息、内存使用情况及系统运行时间。能够初步识别磁盘挂载位置、Swap 使用情况和系统平均负载。

### Linux 基础命令综合练习

通过模拟服务器巡检任务，完成目录创建、文本文件写入、文件复制、目录查看及文件内容对比等操作。练习过程中纠正了命令拼写和相对路径使用错误，最终完成全部任务。
